Installing Ventricle
====================

Ventricle comes as a VST3 and a CLAP plugin. Copy both from the folder for
your computer, then rescan plugins in your DAW. Use the CLAP version if
your DAW supports it.


macOS (Apple Silicon and Intel)
-------------------------------

1. In Finder, choose Go > Go to Folder and enter:
   ~/Library/Audio/Plug-Ins
2. Copy macOS/Ventricle.vst3 into the VST3 folder.
3. Copy macOS/Ventricle.clap into the CLAP folder.
   Create either folder if it isn’t there.

Ventricle isn’t signed or notarized, so macOS may refuse to load it. If your
DAW doesn’t list it after a rescan, open Terminal, run this, then rescan:

   xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/VST3/"Ventricle.vst3" ~/Library/Audio/Plug-Ins/CLAP/"Ventricle.clap"


Windows
-------

Before unzipping, right-click the zip, choose Properties, check Unblock
and click OK. If SmartScreen or your antivirus blocks the download,
choose to keep it.

1. Copy Windows\Ventricle.vst3 into:
   C:\Program Files\Common Files\VST3
2. Copy Windows\Ventricle.clap into:
   C:\Program Files\Common Files\CLAP
   Create either folder if it isn’t there.


Uninstalling
------------

Delete Ventricle.vst3 and Ventricle.clap from the folders above.
